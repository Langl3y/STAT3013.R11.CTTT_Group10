# ClinicAnalytics dataset (simulated)

Synthetic data for a private outpatient clinic in Ho Chi Minh City, Jan 2023 – Dec 2025.
Generated by `src/simulate.py` (seed 3013). No real patient data. Regenerate with `python src/simulate.py`.

| File | Rows | Content |
|---|---|---|
| patients.csv | 5,000 | patient_id, age, gender, insurance, chronic_condition, care_programme, acquisition_channel, main_department, first_visit_date |
| visits.csv | 24,872 | visit_id, patient_id, visit_date, department, total_cost_kvnd, out_of_pocket_kvnd ('000 VND), wait_minutes |
| survey.csv | 1,500 | patient_id + 20 Likert items (1–5): SQ1–4 service quality, DC1–4 doctor communication, AC1–3 access, PF1–3 price fairness, SAT1–3 satisfaction, LOY1–3 loyalty |
